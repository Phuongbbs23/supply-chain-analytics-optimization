## 📖 Overview
This project focuses on supply chain data analysis and optimization, evaluating logistics performance, inventory levels, and operational bottlenecks using Microsoft Excel.

## 📊 Key Metrics Analyzed
- **OTIF (On-Time In-Full):** Order delivery performance.
- **Lead Time:** Average fulfillment duration from suppliers.
- **Inventory Turnover:** Stock efficiency and holding costs.

## 🛠️ Tools & Methods
- **Microsoft Excel:** Pivot Tables, `XLOOKUP`, `SUMIFS`.
- **ABC Analysis:** Pareto principle (80/20 rule) for inventory categorization.

## 🚀 Key Insights
- Identified key suppliers causing delivery delays.
- Proposed optimizations to reduce total logistics costs by ~10%.
